# App de Gestión de pacientes (2025)
### Alumna: **Naiara Gadea Rodríguez Gómez** 
Repositorio con los ficheros de la app de pacientes creada en la asignatura de Aplicaciones para Sistemas de Información Sanitaria y Dispositivos Móviles del [Máster en Ingeniería Biomédica y Salud Digital](https://www.mibsd.us.es/) de la [Universidad de Sevilla](https://www.us.es/).
